# 초안 계획 독립 검토 — 2026-10-05

대상: `implementation-plan.md`의 검토 전 초안(1~145행). 중앙 조사, 분야별 조사, 현재 소스 및 앞선 독립 조사에서 대조한 원본 실행 자료를 기준으로 검토했다. 제품 코드 수정·테스트·라이브 실행·커밋·푸시는 수행하지 않았다.

## 판정

요구와 해결 방향은 타당하다. 합성 행동 금지, 전용 해석기 없는 원본 전달, 실제 세션 출처, 사람 승인 우선, 불확정과 목표 달성의 분리가 계획에 반영됐다. 다만 5절에 남겨둔 선택 중 아래 일곱 항목은 구현 시작 전에 확정해야 한다. 미완성 초안의 선택을 확정하라는 지적이며, 아직 작성하지 않은 제품 구현에 결함이 있다고 주장하는 것은 아니다.

각 항목은 **필수 / 반영 권고**다. 루트가 반영·대안 반영·기각·후속 여부와 근거를 기록하면 된다. 동일 의미의 파일을 반복해서 검토하거나 만점까지 범위를 늘릴 필요는 없다.

## 유지 및 후속 판단

- **유지:** 실제 사용 세션과 계정 연결 근거의 구분, 다른 실행/대상 증거 거절, 사람 승인 후 동일 실행 입력 확인, 실제 목표 조건 검사, 조회를 진행으로 계산하지 않기.
- **기각:** 과거 팀원 실행의 원본이 없다는 이유로 계정/증거 정합성 검사를 일괄 삭제하기, 모든 신규 도구에 합성 행동을 채우기, 기존 외부 전송 금지를 사람 승인으로 바꾸기, 기록 도구를 루트의 숨은 그래프 쓰기로 대체하기.
- **후속:** 전체 컨트롤 플레인 개편, 완료와 다음 행동의 일괄 제출, 모델 비교 실험. 현재 필수 계약을 확정하기 위한 선행은 아니다.
- **검증 보완:** 계획 4절의 사례 목록은 타당하다. 3번 사례는 모델이 원본의 값을 받고 공통 기록 도구를 실제 호출했으며 기록 결과가 다음 판단/루트 문맥에 돌아왔다는 연결을 관측해야 한다. 해석기 없음, 행동 연결 없음, 기록 요청 거절 후 보정, 승인 대기 후 재개를 동일 성공률로 합치지 않는다. 자동 사례와 실제 LLM 실행 확인을 구분한다.

## 자료 제한

팀원 BOLA 실행의 정확한 세션 누락 및 제공자 오류 원인은 첨부된 원본 범위에서 미확인이다. `research-B.md`는 이번 읽기 시점에 `# test` 한 줄뿐이므로 완료/기록 담당의 조사 근거로 사용할 수 없었다. 위 지적의 근거는 해당 문서가 아니라 실제 소스 및 원본 실행 기록이다. 현재 초안과 연구 문서는 동시 작성 중이므로 수정본 검토에서는 확정된 계약과 반영 결과를 확인하면 된다.

대상: `implementation-plan.md`의 최신 2.3절, 5절, 6절(최종 218행)과 이번 요청에서 명시한 정본/정산 결정. **계획 구현을 막는 근거 있는 필수 지적은 더 없다. 계획 검토를 종료한다.** 제품 구현이 완료되었다거나 실행 검증을 통과했다는 판정은 아니다.

- **V1 해소:** 54행과 195행이 같은 정책 의미를 사용한다. 명시된 기존 제한은 실제 선택 도구의 제공자 선언으로 평가하고 표현할 수 없으면 정책 의미 미지원 진단과 설정 안내를 반환한다. 빈 목록은 추가 제한 없음이므로 행동 연결 없는 일반 도구 실행을 막는 조건이 아니다. 합성 행동이나 중앙 이름별 예외가 필요하지 않다.
- **V2 해소:** 189행에 로컬 의미 검토가 현재 요청자의 동일 예산과 호출 전 확인을 받도록 명시했다. 현재 워커 또는 루트에 비용을 귀속하고 도구 처리까지 마친 뒤 실제 사용량 차이를 한 번 정산한다. 예산 부족은 검수 미완료로 보존한다. 실제 모델 호출 없는 제공자 제안은 정상 진행만 계산한다.
- **막힘 정본 확정:** 이번 요청의 명시 지시 및 214행에 따라 기존 증거 저장 영역의 시스템 결과가 상세 원본이고 실행 상태·작업·가설·보고는 참조/요약을 소비한다. 181행에 남아 있는 이전 '실행 상태에 항목 보존, 보고는 이 원본 투영' 문장은 이 최신 결정을 대체하지 않는다. 해당 문구를 참조/요약 보존으로 정리하는 것은 편집상 후속이며 새로운 계약 선택이나 재검토 회차는 필요 없다.
- **R1~R7 처리 인정:** 210~216행의 반영 표와 구체 계약으로 선행 지적의 처리 근거가 연결됐다. 분야별 기능 선택 파일, 실제 원본→워커→공통 기록 TOOL 경로, 승인 지문, 사후 검증·최종 영수증, 불확정 미완료 결과, 정상 판단/보정/실제 사용량 분리의 설계 의미를 확정한 것으로 본다.

이후 전체 diff 리뷰에서는 이 계약들이 발견·등록·공개 입력·실행·승인 재개·로컬 검수·저장·다음 판단·보고까지 실제로 소비되는지 확인한다. 과거 팀원 제공자 실패/세션 누락 원인 미확인 상태는 유지한다. 이번 최종 확인은 최신 계획 읽기와 본 검토 문서 갱신만 수행했고, 제품 코드·테스트·라이브 실행·커밋·푸시는 수행하지 않았다.
