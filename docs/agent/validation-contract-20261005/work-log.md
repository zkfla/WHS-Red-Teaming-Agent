## 첫 checkpoint

제공자 오류 포트/어댑터와 판단 담당 연결, 정상 판단과 오류 보정의 별도 한도 계약을 구현했다. 실제 요청 횟수는 기존 계측을 유지하고, 실제 호출 없는 제공자 결정은 별도 진행 수로 제한한다. 비재시도 제공자 실패는 동일 요청의 자동 보정을 계속하지 않는다.

이 checkpoint는 소스 변경 범위·공개 계약·명백한 오류와 공백만 최소 확인했다. 자동 테스트·라이브 호출·전체 코드리뷰 완료를 뜻하지 않는다. 전체 구현과 독립 코드리뷰가 끝난 뒤 최종 검증을 수행한다.

## 진행 중인 연결

공통 완료 입력·미해결 원본 기록과 단계/작업 전이, 원본 조회 범위 재구성, 로컬 도구 호출 및 비용 귀속, 분야별 도구 노출·실행·재개 구성, 최종 보고를 통합 중이다. 아직 구현 완료·실행 검증 완료·최종 dev 푸시로 판정하지 않는다.

## 후속 checkpoint와 통합 확인

- `bd08c347`: 보고에 조사 미해결 정본, 원본 조회 요청, 실제 판단 사용량과 제공자 진단을 투영했다. 기존 목표 달성 판정은 유지했다.
- `021004cb`: HTTP 요청 실행 시 실제 사용 세션 영수증을 기록했다. 설정된 세션 목록과 실제 사용·계정 입증을 구분한다.
- `0a9156b3`: 실제 등록 도구를 직접 선택하고 분야별 선택 파일을 카탈로그에 연결하는 경로를 저장했다.
- `4f466ad6`: 실제 도구/입력의 승인 지문 영속화, 제공자 의미에 따른 명시 정책 판정과 위험 명령 사람 승인 경로를 저장했다.
- 두 checkpoint는 공백/소스 범위만 확인했다. 기능 테스트와 실제 LLM/MCP 검증은 수행하지 않았다.
- 방법론 읽기의 카탈로그 선택은 실제 제공자 읽기 규격으로 연결했고, 신규 직접 호출의 결과 포착·분야별 참고 자료 문맥 소비를 연결 중이다. 비어 있는 방법론 선택 목록은 기존 분야 기본 문맥을 유지하고, 비어 있지 않은 목록은 그 기본 문맥을 좁힌다.
- 장시간 작업 결과를 회수한 뒤 반환된 검수 사용량이 다음 실행 상태에서 사라지는 연결을 보완했다. 회수 검수도 현재 판단 예산을 공유한다.
- 통합 중 확인한 필수 누락은 담당 워커에게 되돌렸다: 능력 선언만 있는 도구의 명시 행동 정책은 평가 가능하다고 추측하지 않기, 자동 해석기 없는 도구에서 발견한 새 대상도 공통 기록 경로로 등록하기.
- 대상별 명시적 빈 허용 목록은 기존 거부 의미를 보존한다. 계획의 '빈 목록은 추가 제한 없음'이라는 일반화는 이 기존 계약에 맞춰 정정했다. 정책 공개 설명도 두 의미를 나누어 전달한다. 이는 기존 사용자 정책 의미 보존을 위한 대안 반영이며 전체 코드리뷰에서 대조한다.

호환 범위: 옛 제안/호출/저장 상태는 옛 행동 연결 경로와 추가 필드 기본값으로 읽는다. 기존 재개의 실행 구성 동일성 검사는 유지한다. 구성/확장 선언이 달라진 과거 실행을 새 구성이라고 추측해 재개하지 않는다. 이 제약이 새 역할 선택 지문과 만나는 소비 경로는 전체 독립 코드리뷰에서 별도로 확인한다.

## 전체 통합 checkpoint 준비

모든 구현 워커의 담당 결과를 통합했다. 공통 기록은 실제 원본 실행과 측정 값의 일치, 새 대상의 원본 정체성 연결, 사후 취약점 검수 및 최종 영수증을 사용한다. 새 대상이 발견되었다는 기록과 해당 대상에 요청을 실행했다는 기록을 구분하고 실행 허가를 만들지 않는다.

현재 변경 소스 72개는 AST 문법 분석과 공백 검사를 통과했다. 이는 자동 기능 테스트나 라이브 검증이 아니다. 이 통합 checkpoint 이후 외부 Sol High가 기준 커밋 `5bf74684`부터의 전체 변경, 확정 계획, 원본 실패 자료를 독립적으로 리뷰한다. 필수 지적을 수정하고 영향 범위를 재리뷰한 뒤 최종 테스트·실제 LLM/MCP 검증·최종 푸시를 수행한다.

## 선행 변경 분리와 최소 소비 경로 확인

- 첫 checkpoint: f851c179. 계획·조사·검토 문서와 판단 예산/제공자 오류 계약을 보존했다.
- 작업 시작 전에 존재한 CLI 변경은 저장된 선행 patch를 index에 적용해 별도 checkpoint로 분리했다. 작업 트리의 새 중앙 구현을 덮어쓰거나 되돌리지 않았다. 동반 미추적 대상 추출 코드와 그 선행 테스트 파일만 명시적으로 포함했다.
- 확인 중 발견한 필수 연결을 구현 범위 안에서 보완 중이다: 선택 파일의 실제 역할 카탈로그 주입, 명시 정책의 직접 선택 호출 호환, 설정된 세션과 실제 사용 출처의 분리, 실제 첫 취약점 주장 검수, 원본 증거와 새 검수 비용 귀속의 분리.
- 모델의 원본 조회 범위와 로컬 결과는 참조로 보존해 다음 판단에서 다시 읽는다. 새 조사 갈래는 원본 기록에서 루트 문맥으로 투영한다.
- 병렬 실행의 검수 사용량은 기존 워커 결과→집계 계약으로 전달해 부모 실행에 한 번 정산한다. 종료 검토와 원본 재해석 비용도 현재 요청자에 누적한다.
- 워커 일부는 문법 확인(py_compile)만 수행했다고 보고했다. 기능 테스트·실제 LLM/MCP 실행 검증·독립 전체 diff 리뷰는 아직 수행하지 않았다.
