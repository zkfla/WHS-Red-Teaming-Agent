## 1차 재리뷰 잔여 수정

재리뷰는 종료됐고 9건 해결/3건 부분 해결, 잔여 5건 CR13~17을 반환했다. 모두 실제 소스의 실패 조합이 확인돼 반영했다. 관계 속성의 측정은 원본 대상 노드에 보존하고 모델이 제안한 관계 자체는 추론으로 기록한다. 원본 주소로 입증한 새 대상에는 코드가 관측 관계를 생성하며 관계의 값 스냅샷/같은 증거/측정 출처를 소비한다.

사후 최신 판정 그룹은 주장·가설·정규화된 복수 원본으로 계산해 인용 순서가 바뀌어도 동일하다. 가설의 반박은 별도 가설 결과가 있을 때 새 주장 위반 여부와 분리해서 소비한다. PoC는 참조 가설이 미해결인 검수 영수증을 성공 근거로 인정하지 않으며, 실제 승격된 발견 사항의 검토 영수증 또는 같은 주장/원본 그룹의 최신 재확인과 연결한다. 다른 주장의 영수증을 기존 발견 사항에 붙이지 않는다. 옛 발견 사항은 옛 검수 의미로만 읽는다.

완료 계정 별칭 조회는 현재 원본의 실제 사용 세션에 한정했다. 과거 신원 증명은 현재 호출의 사용 증명을 대신하지 않는다. 세 담당 소스 AST/공백만 최소 확인했으며 기능 테스트/라이브 호출은 아직 수행하지 않았다. 수정 통합 후 해당 영향 범위를 외부 리뷰어가 재검토한다.

## 2차 재리뷰 및 CR18

`66630090` 재리뷰에서 CR13~17은 소스 기준 해결됐고, 같은 관계 재관측의 현재 출처가 첫 출처 고정 저장 계약 때문에 거절되는 CR18이 남았다. 이를 반영해 그래프 관계 저장에서 기존 첫 값/출처는 그대로 유지하고, 정확히 같은 값의 새 주장 출처만 제한된 확인 목록으로 보존한다. 기존 전체 출처 목록을 관계 입증으로 사용하는 우회는 없다. 관계 소비자는 공개 조회 함수로 해당 관계 값의 첫/재확인 출처를 읽고 현재 run·증거·측정 등급·유형/끝점 스냅샷을 확인한다.

새 공통 의미는 동일한 관계 값을 재확인한 원본의 연결이다. 기존 단일 첫 출처만으로는 이를 표현할 수 없어 그래프 소유 영역의 공개 함수와 관계 저장 소비를 함께 확장했다. 노드 값/첫 출처 고정 규칙이나 원본 증거는 변경하지 않았고, 기존 최대 출처 개수 제한을 재사용했다. AST/공백 최소 확인만 수행했으며 이 소규모 영향 범위를 외부 재리뷰한 뒤 최종 검증으로 넘어간다.

## 3차 재리뷰 진행 의미 수정

CR18의 재관측 출처 연결은 해결됐으나, 관계 내용 지문이 개별 주장 출처를 그대로 포함해 같은 값·같은 근거 수준의 새 증거도 대기 해제로 읽는 CR19가 확인됐다. 관측 투영 담당에서 개별 출처를 감사 정보로 제외하고, 현재 속성 값과 일치하는 주장들의 근거 수준 집합만 의미로 투영한다. 새 원본 ID나 같은 수준의 확인 개수는 지문을 바꾸지 않으며, 추론→측정 등 근거 수준 변화와 실제 속성 변경은 반영된다. 저장된 출처와 완료의 현재 증거 검사는 유지한다. AST/공백 확인만 수행했고 외부 영향 범위 재리뷰 전 기능 테스트·라이브 실행은 시작하지 않았다.

## 최종 검증 진행

외부 전체 코드리뷰가 CR19까지 해소됐다고 판정한 뒤 자동·실제 검증을 시작했다. 자동 검증에서 실제 게이트웨이의 전체 카탈로그 공개 포트 누락과 복구된 제공자 진단의 최종 보고 누락을 발견해 기존 소유 경계에서 보완했다. 공개 카탈로그 누락은 외부 리뷰가 CR20으로 다시 확인했다. 변경 테스트 묶음, 타입·형식·Compose 구성 검사는 통과했고 실제 stdio MCP로 행동 연결 없는 도구의 직접 호출과 HTTP 200 응답을 확인했다. 실제 LLM CLI 재실행은 조립·MCP 발견을 통과했으나 계정 한도의 HTTP 429로 계획 전에 종료됐다. 세부 결과와 미검증 경계는 `final-validation.md`에 기록했다.

## 선행 변경 분리와 최소 소비 경로 확인

이 절은 첫 통합 전의 과거 진행 기록이다. 현재 상태는 위의 독립 전체 리뷰·리뷰 수정 통합 절을 기준으로 읽는다.

- 첫 checkpoint: f851c179. 계획·조사·검토 문서와 판단 예산/제공자 오류 계약을 보존했다.
- 작업 시작 전에 존재한 CLI 변경은 저장된 선행 patch를 index에 적용해 별도 checkpoint로 분리했다. 작업 트리의 새 중앙 구현을 덮어쓰거나 되돌리지 않았다. 동반 미추적 대상 추출 코드와 그 선행 테스트 파일만 명시적으로 포함했다.
- 확인 중 발견한 필수 연결을 구현 범위 안에서 보완 중이다: 선택 파일의 실제 역할 카탈로그 주입, 명시 정책의 직접 선택 호출 호환, 설정된 세션과 실제 사용 출처의 분리, 실제 첫 취약점 주장 검수, 원본 증거와 새 검수 비용 귀속의 분리.
- 모델의 원본 조회 범위와 로컬 결과는 참조로 보존해 다음 판단에서 다시 읽는다. 새 조사 갈래는 원본 기록에서 루트 문맥으로 투영한다.
- 병렬 실행의 검수 사용량은 기존 워커 결과→집계 계약으로 전달해 부모 실행에 한 번 정산한다. 종료 검토와 원본 재해석 비용도 현재 요청자에 누적한다.
- 워커 일부는 문법 확인(py_compile)만 수행했다고 보고했다. 기능 테스트·실제 LLM/MCP 실행 검증·독립 전체 diff 리뷰는 아직 수행하지 않았다.
