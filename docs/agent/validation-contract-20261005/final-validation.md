## 실제 LLM 실행

첫 실행은 위의 카탈로그 연결 누락을 재현했다. 수정 후 두 번째 CLI 실행은 조립과 MCP 발견을 통과해 실제 모델의 첫 계획 요청까지 진행했다. 모델 제공자는 네 번 모두 HTTP **429**를 반환했고, 실행은 `decision_repair_budget_exhausted`와 내부 원인 `llm_provider_rate_limited`를 구조적으로 기록한 뒤 `Mission: blocked`, 실행 행동 0건으로 종료했다. 계정 사용량 조회도 현재 5시간 창 100% 사용 상태를 확인했다.

따라서 제공자 오류의 분류·원인 전달·보고는 실제 호출로 확인했지만, 실제 LLM이 도구를 선택하고 MCP 결과를 읽어 공통 그래프를 기록한 뒤 완료 또는 미해결로 정리하는 전체 라이브 흐름은 **제공자 한도 때문에 미검증**이다. 이를 성공으로 표시하거나 자동 테스트로 대체하지 않는다.
