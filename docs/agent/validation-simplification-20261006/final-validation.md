## 확인한 부담 변화와 한계

같은 합성 판단 문맥·같은 원본으로 실제 검수 요청을 조립한 비교는 단계 9137→3171자, 작업 9602→2811자, 목표 9893→2755자다. 각각 실제 검수 한 번이며 관련 등록 상태·권한·근거를 보존한다. 이는 고정 예제의 문맥량 비교이며 전체 모델 성공률·토큰 비용·시간 개선율이 아니다. 잠정 초안은 자동 검사에서 추가 모델 검수 없이 open으로 보존되고, 마지막 판단의 미해결은 추가 모델 호출 없이 정산된다.

라이브 시간과 호출 수는 실제 수치로 남기되 이전 소스/다른 목표의 실행과 비교해 인과적 개선율을 만들지 않는다. 소수의 작은 반복 사례로 모든 조사·취약점 발견·외부 제공자 동작의 무오류를 입증하지 않는다. 범위 밖 동작은 검증하지 않으며 외부 제한은 성공으로 바꾸지 않는다.

최신 양성 05·06은 모델 요청 각각 16회, 공급자 응답 대기 합계 약 103.36초/89.30초였다. 미해결 09·10은 모델 요청 12회/16회였다. 06은 정상 판단 레인의 여유 부족 진단 1건 뒤 다음 차례에서 정상 목표 정산됐으며 최종 planning 진단은 없다. 이 중간 진단을 최종 실패로 바꾸거나 기록에서 지우지 않았다. 마지막 판단에서 미해결 정산을 수용하는 R3 효과는 예산 경계 자동 재현으로 확인하며, 네 라이브 모두 그 특정 경계에 도달했다고 주장하지 않는다.
