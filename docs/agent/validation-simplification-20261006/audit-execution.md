## 과장 정정 (1차 보고 대비)

- 단계/작업/목표를 단순 동일 검수 반복으로 표현한 부분을 정정한다. 목적이 다르다. 단계는 고정 기준과 실제 증거 대조, 작업은 위임 목적과 저장 원본에 대한 의미 검토, 목표는 원래 운용자 기준과 필수 작업 커버리지 정산이다.
- 최종 정산이 기준을 재사용하지 않는다는 뉘앙스를 정정한다. 작업, 목표 정산이 쓰는 단일 원본 증명과 영수증 연결 검사를 최종도 같이 쓴다. 최종 보고 자체는 읽기 전용 투영이다.
- 정상 8/보정 3이 분리되지 않았다는 뉘앙스를 정정한다. 이미 정상 한도와 보정 한도가 분리돼 있다. 남은 검토는 숫자 변경이 아니라 정상 시도 예산 잠식 여부뿐이다.
- 발췌 캐시를 새로 추가한다는 뉘앙스를 정정한다. 새로 만들지 않는다. 기존 문맥 투영 담당과 발췌 상한을 재사용한다.
- 의심 자료형/스키마 경고성 표시는 새 확정 검사로 추가하지 않는다. 값 복사 없는 진단 전달만 허용한다.
