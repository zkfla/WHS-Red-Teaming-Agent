# 조사 방법론 프롬프트 보강 — 2026-10-16

사용자가 기존 비교 문서를 바탕으로 ARTEX 원문의 핵심 방법론을 더 명확하게 적용하도록 요청했다. 기존 한국어 프롬프트·출력 계약을 유지하면서 다음 행동 우선순위를 강화했다. 비교 기준 원문은 로컬 `data/prompt-comparison-20261016/`에 보존되어 있으며, 이 기록은 타 시스템보다 우월한 성능을 입증하지 않는다.

- 전략·계획자는 깊이를 커버리지보다 우선하고 가장 강한 고가치 증거 경로를 먼저 진전시킨다. 증거와 범위가 뒷받침하는 경우 목적·진입점·기제가 실제로 다른 2~3개 경로를 유지한다. 작업 수를 맞추기 위한 중복 경로는 만들지 않는다.
- 뒤 단계가 앞 단계 산출물에 의존하면 실제 결과가 생긴 뒤 출처·대상·내용을 검증하고 다음 질문·실행을 제안한다. 전략의 질문 생성과 아토마이저의 독립 작업 분해 책임은 유지한다. 미래 결과를 가정한 의존성 DAG를 새 출력으로 추가하지 않는다.
- 워커는 실패 진단과 새 원본 관측에 따라 적용 가능한 다른 방법으로 이어가고, 도구 호출 개수 대신 저장된 완료 조건과 원본 증거로 진전을 설명한다.
- 현재 후보 ID·revision·purpose에 정확히 결속된 독립 공개 검토는 원본과 대조하여 후보 갱신에 활용한다. 이미 충족된 검토 전제는 중복 요청하지 않는다. 검토 기록·후보 판정·Finding·Mission 완료는 각 코드 게이트에서 구분한다.
- `held`는 유용한 경로를 막는 구체적 현재 선행 조건, `exhausted`는 증거에 따른 유용한 허용 경로 소진으로 구분한다. 이유와 재평가를 정당화할 새 증거·변경 조건을 사실대로 남긴다.
